# Conditions are derived, never stored

What an action sees about a thing (buried, frozen to the ground, occupied, wet) is a condition read from the thing's effects and its place, never a stored flag. A blocking condition has one clearing action, which changes the world (digging lowers the snow over it) rather than the condition, so a thaw or a fire beside it also clears it with no special action. Conditions replace the tags of build step 2. Occupied blocks; its clearing action, Contest (Ask toward an ally), is answered by the occupant's own mind, which replaced a "guarded" refusal gate.
