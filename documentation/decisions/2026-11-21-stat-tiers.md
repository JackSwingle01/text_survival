# Stat tiers decide priority before the stat hierarchy

Every stat (warmth, water, food, rest) is Critical (imminent death), Need (survive the day, or back to baseline) or Want (stockpile, surplus). Tier ranks first; within a tier, warmth beats water beats rest beats food. This replaced a rule that made food critical once fat fell below the 10% floor: at the floor a person still holds weeks of reserve, while a night without wood kills in hours, and NPCs following the old rule foraged all day and froze. Fat below the floor is now Need, and tonight's fuel (warmth, Need) outranks it.

Amended 2026-11-22: rest beats food, as the code and glossary already had it, and animals rank food, water and rest on the same ladder.

Renamed 2026-11-22: tiers are now called priorities (`GLOSSARY.md`). The title keeps the old word so references to it still resolve.
