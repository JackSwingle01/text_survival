# Death is final

Death deletes the save, and the game autosaves while you are alive. A run is one life, so a bad
crossing or a lost fight cannot be loaded away, and tension and the stakes of each choice rest on
that. This is faithful to the old game; the rebuild had offered "Load your save" on the death screen,
which is the obvious thing for a web page with a save slot, and is what we turned down.
