# No effect needs a treatment the game doesn't have

An effect's floor that only a treatment can clear is allowed only when that treatment exists in the
game. Bloody fades on its own: it dries over a few hours, faster by a fire, with no washing action.
Shock's untreatable floor goes too. The old game kept blood at a floor until "washing", which it
never offered, so one butchering marked the player as a scent source for the whole run; frostbite
never healed for the same reason. When treatment arrives (roadmap 11) an effect can gain a floor
again, together with the action that clears it.
