# One Make activity for crafting and building, with outcome tables as data

Crafting an item and building a shelter are the same thing: a recipe (inputs, tools by capability, place requirements, work, a result) made through one Make activity that the player and NPCs share, interruptible and resumable as a project. Each recipe's possible departures from its plain result are a data table of outcomes with base odds (`succeed|fail[:effect:params]=<odds>`, `|` for evenly split alternatives), with a closed list of effects: wasted or saved material, an extra product, an injury, a broken tool. The old game had 71 deterministic recipes written in code and a separate building-project path; one shape removes the duplicate, lets skill shift odds in one place, and makes new risks a data row rather than code.
