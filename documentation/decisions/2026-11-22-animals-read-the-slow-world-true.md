# Animals read the slow world true and sense what moves

Animals have no Memory. Anywhere on the map, they read the true state of things that stay put or
change slowly: terrain, water, dens, how grazed a tile is. Things that move (prey, predators,
carcasses, fresh prints) they know only by sensing them now, plus a short sightings list that
expires. Full Memory per animal would cost tens of MB of save. A learned range was rejected because
real ranges are at or beyond the size of the map (wolf territories run 100-1,000+ km², and the map
is about 92 km²). People keep Memory because the player sees and reasons about what a person knows,
and nobody would see an animal being out of date about grazing. Both feed the same planner. The
fixed territory is gone with this; a den is only a place to rest.
