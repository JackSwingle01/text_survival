# Authored predator content coverage

Updated September 6, 2026. The previous generic-menu restoration assessment is superseded. The original event files and registrations have been restored. Of 95 archived outcome declarations, 91 are present verbatim and four have adapted wording. This measures source-content preservation, not identical execution: movement, fire, bait, and harvesting responses use physical actions and report their actual results.

Twenty authored scene kinds have explicit source/situation rules, including all 19 scenes in the catalog regression test plus Something Watching. Incidental predator branches bind a visible animal of the stated species. Old predator tension lifecycle popups remain replaced by observation-driven scene selection; they do not run as a second escalation system.

## Execution changes

- Source identity survives input and time; dead/missing sources and changed prerequisites invalidate the relevant scene or outcome.
- Fishing requires fishing and its local water/net feature. Carcass scenes require an accessible carcass; Wolves Smell Blood specifically requires a mammoth and butchering. Trap scenes require local bait/catch.
- Scavenger's Gambit requires a feeding wolf and actual visible hyenas. Its second-wolf-pack branch requires another visible wolf herd.
- Travel choices use traversable neighboring ground. Fire-start choices use tools/materials and the fire handler. Fish and meat dropped as bait become actual ground resources.
- Harvest choices consume carcass yield rather than producing reward-pool meat. Grab-and-run choices then travel away.
- Authored follow/withdraw reactions change the bound herd; no Stalked/Hunted/PackNearby severity is created.
- Random authored reactions and atmospheric descriptions remain. This is not a new simulation of every local gesture, twig, or sound.
