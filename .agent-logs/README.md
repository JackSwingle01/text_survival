# Agent work logs

These files are committed on purpose. Each is an agent's work log for one task: the hypothesis it
made before writing code, a `Revised:` line each time reality disagreed, and `Follow-up:` lines for
work it found outside its scope (the `mp:work-log` skill's format).

They are kept in the repo to record how agents worked and to debug them: to see what an agent
expected, where it was surprised, and what it changed its mind about. They are not documentation of
the game; design lives in `documentation/` and terms in `GLOSSARY.md`.

One file per task, named `YYYY-MM-DD-short-name.md`, dated the day the work started.
