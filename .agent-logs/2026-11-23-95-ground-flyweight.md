# #95: Ground is a flyweight: every tile reads its class's state, and everyone reads it the same way

Hypothesis:
- Changes: Ground (CatchUp/Peek stop storing; new Ground.Write, the one tile write; per-tile state steps beside an unsaved class shadow and drops back when within tolerance), Trip/Travel (GroundRead.Estimate, GroundReadOf, the *Estimate reads go), World (unsaved shadow cache), tests that set up snow by mutating CatchUp's result.
- Affects: every ground read (travel minutes, hazard, contact wetting, search, burial, memory of ground); today an observed tile stores a private copy in World.Tiles (on main, after 30 populated days: 1 ground tile stored on seeds 17 and 23, since animals read the Estimate); what is read does not change because only weather writes ground today.
- Stays green: GroundTests (bar the store-on-read ones), TripTests, travel/NPC/herd tests, SaveFixtureTests after regeneration, determinism tests, ConservationGroundTests.
- First red: a new GroundTests test that reads a tile on a seeded world and finds no Ground in World.Tiles fails on the stored copy.
- Baseline (main, Release, 30 days Sim.Advance): seed 17 10.9 s, 4861 MB, save 835 KB, 1 ground tile; seed 23 7.3 s, 5358 MB, save 873 KB, 1 ground tile.

Revised (review): a layer-by-layer tolerance never drops a buried trench (packed snow under fresh stays far apart in compaction for weeks) → "within tolerance" compares what the ground reads as (snow depth, traversal factor, hazard, standing water, wetness, contact wetting), not its layers.
Revised (review): dropping at write time would swallow small writes, so repeated light trampling could never add up → Ground.Write always stores; the fallback is checked only as the tile's own state steps (and once before stepping, so a state loaded from an old save drops at its first read).
Revised (review): a shadow rebuilt for a tile lagging the class cache replays from the history start → the shadow is made at write time from the class at that minute (the cache is at or near now), and rebuilt only after a load or a sky change; Peek keeps the shadow it rebuilds (an unsaved cache).
Revised (review): CatchUp hands back the live own state but a throwaway class copy otherwise → reads only; Ground.Write is the one write, and the tests that set up snow by mutating CatchUp's result move to it.
